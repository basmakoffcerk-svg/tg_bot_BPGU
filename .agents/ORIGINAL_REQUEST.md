## Requirements

### R1. Серверный бэкенд и База Данных (FastAPI + SQLAlchemy 2.0 Async + SQLite)
Реализовать единый асинхронный сервис с базой данных SQLite (режим WAL):
- Хранение моделей данных: студенты группы 240326 Матинф БГПУ (вайтлист, подгруппы 1 и 2), расписание пар (корпуса БГПУ, геоточки, время звонков), реестр пар, журнал посещаемости, аудит-лог. Полная схема описана в docs/DATABASE.md.
- Криптографическая валидация Telegram initData по алгоритму HMAC-SHA256 с ролевым контролем (Студент / Замстаросты / Староста) согласно docs/ARCHITECTURE.md.
- REST API для Mini App: аутентификация, выдача расписания дня, геочекин студента (формула гаверсинусов d <= 150 м, accuracy <= 50 м, временное окно пары), интерактивная шахматка для старосты, ручной оверрайд статусов и лок пары согласно контрактам docs/API.md.

### R2. Telegram-бот (aiogram 3.x)
Реализовать интерактивного Telegram-бота:
- Онбординг студентов: выбор своего ФИО из вайтлиста группы 240326 Матинф и подтверждение старостой в 1 клик через инлайн-кнопки.
- Кнопка вызова Telegram Mini App (Menu Button / WebApp).
- Модуль рассылки: критические оповещения (@all в чат группы + персональные ЛС каждому студенту) и обычные объявления.
- Получение сформированной Excel-рапортички старостой прямо в чат Telegram.

### R3. Фронтенд Telegram Mini App (TMA SPA)
Реализовать адаптивное клиентское веб-приложение для Telegram в webapp/:
- Вкладка студента: карточки расписания на сегодня, таймер обратного отсчета до окна чекина, кнопка «Отметиться на паре» с вызовом Geolocation API (getCurrentPosition), отображение результата и дистанции.
- Вкладка старосты/админа: интерактивная шахматка со студентами группы 240326, цветовая индикация (зеленый/серый/желтый/синий/фиолетовый), кликабельная смена статусов, модальное окно указания уважительной причины, кнопка «Зафиксировать пару» и выгрузка отчета.

### R4. Генератор официальной ведомости деканата (openpyxl)
Сформировать модуль выгрузки рапортички в формате .xlsx:
- Соответствие университетскому стандарту: шапка (БГПУ, факультет физико-математического образования, группа 240326 Матинф), таблица студентов по алфавиту с отметками по дням и парам, итоговый подсчет пропущенных часов (Н/У) по каждому студенту и суммарно по группе.
- Фоновый еженедельный триггер формирования отчета старосте в субботу в 16:00 (APScheduler).

## Acceptance Criteria

### Функциональная работоспособность и верификация
- [ ] Сервер успешно запускается без ошибок и отвечает 200 OK на /api/v1/health.
- [ ] Валидатор initData корректно пропускает валидную подпись Telegram и возвращает 401 на поддельные/просроченные данные.
- [ ] Модуль геочекина при тестовых координатах в пределах 150 м корпуса фиксирует PRESENT, а при координатах вне радиуса — возвращает 400 Bad Request с указанием расстояния.
- [ ] Эндпоинты шахматки возвращают список группы 240326 с актуальными статусами и позволяют старосте менять статус на MANUAL_CONFIRM / ABSENT_EXCUSED.
- [ ] Генератор отчетов создает корректный валидный .xlsx файл, содержащий всех студентов группы и формулы подсчета часов.
- [ ] Автоматические тесты (pytest / httpx) покрывают ключевые сценарии: валидация координат, смена статуса, права доступа RBAC.
