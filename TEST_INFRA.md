# ТЕСТОВАЯ ИНФРАСТРУКТУРА И ОТЧЕТ О ВЕРИФИКАЦИИ

## Проект: АРМ Старосты («Пульт управления группой 240326» БГПУ)

### 1. Архитектура тестирования
Комплекс тестов построен на базе `pytest`, `pytest-asyncio`, `pytest-cov`, `httpx` (ASGITransport) и `openpyxl`.

### 2. Запуск тестов
```bash
# Активация виртуального окружения
source .venv/bin/activate

# Запуск полного набора тестов
pytest -v

# Запуск с детальным отчетом о покрытии кода
pytest --cov=. --cov-report=term-missing
```

### 3. Карта покрытия тестами (34 сценария)

| Модуль | Тестовый файл | Сценарии | Статус |
| :--- | :--- | :--- | :---: |
| **Криптография & InitData** | `tests/test_auth.py` | Валидация HMAC-SHA256, отсечение просроченных данных (>24ч), защита от подделки хеша, обработка пустых/битых строк | ✅ PASS |
| **Двухфазный Geofencing** | `tests/test_geo.py` | Точный расчет формулы гаверсинусов, Fast-path Bounding Box, фильтрация accuracy (>50м), anti-spoofing дрейфа часов | ✅ PASS |
| **Жизненный цикл пары & Чекин** | `tests/test_attendance.py` | Чекин в радиусе 150м, отклонение вне радиуса, валидация окон времени (T-5..T+15), блокировка пары, оверрайды | ✅ PASS |
| **REST API (FastAPI)** | `tests/test_api.py` | Health-check, ролевая модель RBAC (Студент vs Староста/Зам), выдача расписания дня, шахматка, оверрайды, алерты, экспорт | ✅ PASS |
| **Генератор рапортичек (.xlsx)** | `tests/test_excel.py` | Создание файла Excel, соответствие университетскому стандарту БГПУ, формулы подсчета академических часов (1 пара = 2 ч) | ✅ PASS |
| **Telegram Bot (aiogram 3.x)** | `tests/test_bot.py`, `tests/test_bot_handlers.py` | Онбординг из вайтлиста, пагинация списка, апрув старостой в 1 клик, команды `/start`, `/help`, `/status`, `/report` | ✅ PASS |
